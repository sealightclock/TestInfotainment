# Coding Agent Guidelines

## Core Principles
- **Implement what has been requested:** Focus on fulfilling the specific requirements of the task.
- **Minimize code logic changes:** Avoid unnecessary refactoring or logic alterations unless required for the task.
- **Maintain consistency:** Keep original comments and coding style unless changes are explicitly needed.

## Documentation Standards
- **Class & File Level:** Add comments for each class, object, or file to explain its purpose.
- **Special Functions:** Provide descriptive comments for complex or non-obvious functions.
- **Code Blocks:** Explain special or intricate code blocks within functions.
